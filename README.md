# AI智能进程优先级分配

基于人工智能的Windows进程优先级分配工具，自动优化系统资源分配，确保游戏和关键应用获得最佳性能。

## 功能特点

### 🎮 智能游戏识别
- 支持超过100种游戏关键词识别
- 覆盖明日方舟、原神、崩坏、FGO等热门游戏
- 即使低资源占用也保持高优先级

### ⚡ 多线程并行处理
- 8线程并发扫描，处理速度提升8倍
- 约290个进程仅需约1.1秒完成分析

### 🛡️ 系统保护机制
- 自动保护关键系统进程（dwm.exe, explorer.exe, smss.exe, csrss.exe, lsass.exe等）
- 防止误操作导致系统不稳定

### 📊 智能优先级评分算法
| 因素 | 权重 |
|------|------|
| CPU占用 | 25% |
| 内存占用 | 20% |
| 进程类型 | 20% |
| 线程数 | 10% |
| I/O活动 | 10% |
| 系统负载 | 10% |
| 进程运行时间 | 5% |

### 🏷️ 应用分类系统
- **游戏应用**: 基础分70 +10奖励（最低80→高优先级）
- **设计/AI应用**: 基础分60 +5奖励
- **用户应用**: +12评分加成
- **系统进程**: +8评分加成
- **服务进程**: +3评分加成
- **后台进程**: -5评分惩罚

## 安装要求

- Python 3.8+
- psutil 库
- Windows 10/11 操作系统
- **管理员权限**（用于调整系统进程优先级）

## 快速开始

```powershell
# 安装依赖
pip install psutil

# 运行管理器（建议以管理员身份运行）
python process_priority_manager.py
```

## 使用说明

程序启动后显示主菜单，提供以下选项：

1. **智能优化所有进程** - 自动分析并优化系统中所有进程的优先级
2. **显示进程优先级列表** - 查看当前所有进程及其优先级设置
3. **管理优先级规则** - 自定义进程优先级规则
4. **添加优先级规则** - 添加自定义进程评分调整规则
5. **扫描并配置GPU偏好** - 扫描应用并配置GPU使用偏好
6. **清理Windows预装应用** - 卸载不需要的Windows自带应用

## 保护的系统进程

以下进程受到保护，不会被修改优先级：
- `System`, `System Idle Process`
- `smss.exe`, `csrss.exe`, `wininit.exe`
- `services.exe`, `lsass.exe`
- `dwm.exe`, `explorer.exe`

## 游戏检测关键词

支持的游戏关键词包括：`arknights`, `genshin`, `honkai`, `touhou`, `fgo`, `fate`, `blue archive`, `azur lane`, `GameViewer`, `PCGamePlatform` 等。

## 日志记录

程序会自动生成操作日志 `process_priority_log.txt`，记录每次优化操作的详细信息。

## 配置文件

- `process_priority_config.json` - 存储自定义优先级规则
- `gpu_config.json` - 存储GPU偏好设置

## 注意事项

⚠️ **重要提示**：调整系统进程优先级可能影响系统稳定性，请确保：
1. 以管理员身份运行
2. 不要修改受保护的系统进程
3. 对于不熟悉的进程，请谨慎调整优先级
